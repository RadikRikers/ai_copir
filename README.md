# AI Copywriter Agent

Рабочий веб-инструмент для отдела, который сохраняет стиль копирайтеров и помогает выпускать тексты, когда человек в отпуске, декрете или недоступен.

## Возможности

- несколько аккаунтов сотрудников;
- любое количество агентов-копирайтеров;
- переименование агентов и заметки для отдела;
- обучение на текстах, файлах и изображениях;
- блокировка полноценной генерации, пока агент не набрал минимум базы;
- защита от переобучения: профиль компактный, правки добавляются как переносимые правила, а не как случайные факты;
- вкладка правок: работа ИИ + идеал человека → анализ ошибок → обновление профиля;
- вкладка рекомендаций: книги, письма редактора, методички, правила вроде "Пиши, сокращай";
- облачная синхронизация между администраторами через Postgres + SSE;
- адаптивный интерфейс для компьютера и телефона.

## Минимум для обучения

Приложение считает агента готовым, когда загружено:

- минимум 6 материалов автора;
- минимум около 2500 знаков живого текста.

Если материалы короткие, лучше загрузить 10-12 постов. Больше можно, но агент использует компактную выборку и профиль, чтобы не переучиваться и не тупеть от случайных текстов.

## Профессиональная рамка

При генерации агент работает как специалист с образованием не ниже бакалавриата журналистики и опытом не менее 5 лет в журналистике и копирайтинге. Методические рекомендации усиливают качество, но не заменяют стиль конкретного автора.

## Технологии

- Next.js App Router;
- Vercel;
- Neon Postgres через `DATABASE_URL`;
- OpenRouter Free Router, Gemini или OpenAI-compatible LLM endpoint;
- Server-Sent Events для синхронизации открытых вкладок.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

В `.env.local`:

```env
DATABASE_URL=postgresql://...
APP_ACCESS_CODE=сложный_код_для_админов
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=...
OPENROUTER_MODEL=openrouter/free
AI_FALLBACK_PROVIDER=gemini
LLM_REQUEST_RETRIES=3
LLM_TIMEOUT_MS=45000
```

Откройте `http://localhost:3000`.

## Доступ

Для релиза задайте `APP_ACCESS_CODE` в Vercel Environment Variables. Тогда все API, кроме проверки здоровья `/api/health`, будут закрыты кодом администратора. Если переменная пустая, приложение работает без входа, что удобно только для локальной разработки.

## Нейронка

Бесплатный вариант по умолчанию:

```env
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-...
OPENROUTER_MODEL=openrouter/free
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
AI_FALLBACK_PROVIDER=gemini
LLM_REQUEST_RETRIES=3
LLM_TIMEOUT_MS=45000
```

`openrouter/free` сам выбирает доступную бесплатную модель и фильтрует её под возможности запроса: текст, изображения, JSON-ответы. У бесплатного режима есть дневные лимиты, поэтому для отдела это хороший старт и тестовый режим, но при активной работе может понадобиться платный лимит или отдельный корпоративный ключ.

Альтернатива через Gemini:

```env
AI_PROVIDER=gemini
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-2.5-flash
```

Если добавить `GEMINI_API_KEY` вместе с `AI_FALLBACK_PROVIDER=gemini`, приложение попробует Gemini автоматически, когда бесплатный OpenRouter временно отдаст 502/503/504 или не вернет корректный JSON.

Если `AI_PROVIDER` не задан, приложение само выберет провайдера по найденному ключу в таком порядке: OpenRouter, Gemini, OpenAI.

## Деплой на Vercel

1. Создайте проект на Vercel из папки `ai-copywriter-agent`.
2. Подключите Neon Postgres и добавьте `DATABASE_URL`.
3. Добавьте `APP_ACCESS_CODE`, чтобы закрыть рабочую базу от посторонних.
4. Добавьте переменные для бесплатной нейронки: `AI_PROVIDER=openrouter`, `OPENROUTER_API_KEY`, `OPENROUTER_MODEL=openrouter/free`, `LLM_REQUEST_RETRIES=3`, `LLM_TIMEOUT_MS=45000`.
5. Запустите деплой.

Таблицы создаются автоматически при первом обращении к API.
