# AI Copywriter Agent

Рабочий веб-инструмент для отдела, который сохраняет стиль копирайтеров и помогает выпускать тексты, когда человек в отпуске, декрете или недоступен.

## Возможности

- несколько аккаунтов сотрудников;
- любое количество агентов-копирайтеров;
- переименование агентов и заметки для отдела;
- обучение на текстах, файлах и изображениях;
- блокировка полноценной генерации, пока агент не набрал минимум базы;
- защита от переобучения: профиль компактный, правки добавляются как переносимые правила, а не как случайные факты;
- вкладка правок: работа ИИ + идеал человека → анализ ошибок → обновление профиля;
- вкладка рекомендаций: книги, письма редактора, методички, правила вроде "Пиши, сокращай";
- облачная синхронизация между администраторами через Postgres + SSE;
- адаптивный интерфейс для компьютера и телефона.

## Минимум для обучения

Приложение считает агента готовым, когда загружено:

- минимум 6 материалов автора;
- минимум около 2500 знаков живого текста.

Если материалы короткие, лучше загрузить 10-12 постов. Больше можно, но агент использует компактную выборку и профиль, чтобы не переучиваться и не тупеть от случайных текстов.

## Профессиональная рамка

При генерации агент работает как специалист с образованием не ниже бакалавриата журналистики и опытом не менее 5 лет в журналистике и копирайтинге. Методические рекомендации усиливают качество, но не заменяют стиль конкретного автора.

## Технологии

- Next.js App Router;
- Vercel;
- Neon Postgres через `DATABASE_URL`;
- OpenAI SDK или совместимый LLM endpoint;
- Server-Sent Events для синхронизации открытых вкладок.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

В `.env.local`:

```env
DATABASE_URL=postgresql://...
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4o-mini
```

Откройте `http://localhost:3000`.

## Деплой на Vercel

1. Создайте проект на Vercel из папки `ai-copywriter-agent`.
2. Подключите Neon Postgres и добавьте `DATABASE_URL`.
3. Добавьте `OPENAI_API_KEY` и `OPENAI_MODEL`.
4. Запустите деплой.

Таблицы создаются автоматически при первом обращении к API.
